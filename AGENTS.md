# UBEM-Link: instructions for AI coding agents

This is the canonical instruction file for AI agents (Claude Code, Copilot, Codex, Cursor). `CLAUDE.md` points here.

UBEM-Link is a LinkML schema, a concept vocabulary, a catalog of open datasets and a tool (`ubem-link`) for the
open data of urban building energy modeling. The repository also regenerates every number of the companion paper.

## Layout

| Path | Purpose |
|---|---|
| `schema/ubem_link.yaml` | The schema (single source of truth). Every class, slot and enum value has a description. |
| `schema/vocab/ubem_concepts.yaml` | Concept vocabulary (SKOS); `units.yaml` unit vocabulary with conversion factors |
| `schema/mappings/ubem_link.sssom.tsv` | Mappings to Brick, BEDES and the CityGML Energy ADE (generated by `scripts/make_sssom.py`) |
| `schema/generated/` | JSON Schema, SHACL, OWL compiled from the schema. Never edit by hand. |
| `schema/ai/` | Schema card, concept cards, dataset cards (generated by `python -m ubem_link.ai_docs`) |
| `catalog/datasets/*.yaml` | One DatasetProfile per open dataset; must validate |
| `examples/nyc/` | Sample data, reviewed profiles and an integration recipe; must validate and integrate (tests) |
| `src/ubem_link/` | Package: `cli.py`, `profiler.py`, `readers.py`, `apply.py`, `integrate.py`, `units.py`, `conventions.py` (tool); the other modules run the paper's experiments |
| `docs/` | Documentation site (mkdocs); `docs/reference/` and three pages are generated |
| `benchmark/` | Items, gold labels and cached model outputs of the paper. Never edit cached outputs. |
| `paper/` | Manuscript source and generated tables and figures |

## Commands

```bash
pip install -e ".[dev,schema]"
python -m ubem_link.validate                  # catalog against the JSON Schema
pytest -q                                     # tests, including the tool with a scripted model
python -m ubem_link.ai_docs                   # regenerate schema/ai/
python scripts/make_docs.py                   # regenerate docs/category-profiles.md, vocabulary.md, catalog.md
python scripts/make_examples.py               # regenerate examples/nyc/*.reviewed.ubem.yaml and recipe.yaml
```

After editing `schema/ubem_link.yaml`, regenerate `schema/generated/*`, `src/ubem_link/datamodel.py`,
`docs/reference/` (see `docs/tutorials/05-extend-the-schema.md`).

## Rules

1. The prose of dataset conventions (`applies_to`, `rule`, `example`) and the cards built from it are part of the
   paper's prompts; changing them changes cached experiments. Add machine-readable fields instead, and check that
   `git status schema/ai/dataset_cards` shows no change for existing entries.
2. Catalog facts come from publisher pages or peer-reviewed descriptors only; write `null` when a fact is not stated.
3. Never commit API keys; credentials live in a git-ignored `.env`.
4. Do not change `benchmark/results/cache/*.jsonl` except by running the experiments.
5. To profile a dataset for a user, follow `.claude/skills/ubem-link-profile/SKILL.md`.
