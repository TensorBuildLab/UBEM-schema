# EUBUCCO: European building stock characteristics in a common and open database (geo-eubucco)
- UBEM workflow roles: geometry_inventory, building_characteristics
- Statistical nature: compilation
- Finest public spatial granularity: building
- Temporal resolution: static
- Access: open_download
- Join keys: geometry, lat_lon, building_id, building_type, vintage
- License: ODbL-1.0 (Prague CC-BY-SA and Abruzzo CC-BY-NC sources keep their own licenses)
