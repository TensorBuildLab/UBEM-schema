# Automation in Construction: submission checklist

Checked against the journal's Guide for Authors on 2026-11-13. Rebuild every file in this folder with
`python scripts/graphical_abstract.py` and `python scripts/build_docx.py`.

## Files to upload

| Item | File | Requirement met |
|---|---|---|
| Manuscript | `manuscript.docx` | Editable Word, single column, no underline or strikethrough, continuous line numbers on the left from the title page, page numbers |
| Highlights | `highlights.docx` | Separate file with "highlights" in the name; 5 bullets, each at most 84 characters (limit 85) |
| Graphical abstract | `graphical_abstract.tif` (or `.pdf`) | Separate file, 2656 x 1000 px (min. 1328 px wide), landscape, readable at 13 cm; plotted from the data |
| Figures | `Figure_1` to `Figure_5` (`.pdf` vector, `.png` 600 dpi) | One file per figure, numbered in order of appearance; PNG width 3360-4200 px (min. 2244 px full page) |
| Cover letter | `cover_letter.docx` | |
| Declarations | Elsevier declarations tool, uploaded as .docx at submission | Competing interests ("I have nothing to declare" if none) |
